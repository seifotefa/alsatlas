# ReferALS mapping

Source: [ALS Canada ReferALS early referral tool](https://als.ca/resource/referals-early-referral-tool/). The public resource is the clinical reference for this project; it is not a diagnostic algorithm.

Current status: source reviewed for scope, but no automated clinical rule is enabled yet. The app must not invent thresholds or urgency levels. Until the source PDF/tool content is captured into a versioned local reference, referral support remains a clinician-facing organization workflow only.

Planned mapping format:

| App observation | ReferALS indicator / exact source location | Requires clinician confirmation | App action |
|---|---|---|---|
| Patient-reported weakness | To be populated from the official tool | Yes | Include in report as reported observation |
| Speech or swallowing change | To be populated from the official tool | Yes | Include in report and suggest clinical discussion |
| Progression / functional limitation | To be populated from the official tool | Yes | Include dated timeline |

No row above is currently used to diagnose, exclude ALS, assign emergency status, or calculate a probability.
