# Roadmap

1. Obtain the original DREAM/PRO-ACT visit-level definitions and establish the exact `dFRS` formula, index date, prediction horizon, and subject-disjoint temporal evaluation protocol.
2. Complete authorized ALS Focus access, preserve its questionnaires/data dictionaries, and build a separate longitudinal ingestion/quality pipeline without merging incompatible tables.
3. Add repeated cross-validation and bootstrap confidence intervals, subgroup error analysis, feature-coefficient reporting, external validation, and model-card governance before exposing any prediction endpoint.

Later phases can implement the append-only measurement API and accessible draft/resume workflows, then sponsor integrations behind explicit privacy and consent controls. Gemini extraction must remain reviewable; Tiger Data should store typed time series; Solana must receive only nonclinical receipt identifiers; ElevenLabs needs text parity; Vultr deployment follows threat modeling and secrets/storage design.
