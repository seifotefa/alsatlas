# Raw data

Downloaded source files live here and are immutable inputs. They are ignored by Git because dataset redistribution and size constraints vary. Recreate them with `python scripts/prepare_data.py --download` or place an authorized copy at the documented path.

Currently expected:

- `casidata/ALS.txt` — authoritative text export linked by CASIdata.
- `gaitndd/gaitndd-1.0.0.zip` — PhysioNet source archive.

Never place patient uploads or identifiable health records here.
